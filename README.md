# Otzaria 3D Logo

מודל תלת־ממדי של לוגו אוצריא: ספר פתוח בגימור זהב עם סמל מרכזי מובלט.

## קבצים
- `assets/site-logo.png` — תמונת המקור.
- `models/otzaria_logo_3d.glb` — מודל צבעוני, מתאים ל-Blender ולתצוגה בתלת־ממד.
- `models/otzaria_logo_3d.stl` — מודל ללא צבע, לתוכנות עיבוד/הדפסת תלת־ממד.
- `scripts/build.py` — מחולל המודל.
- `.github/workflows/build.yml` — הורדת המקור, בניית המודל ושמירת התוצרים למאגר.

המודל הוא שחזור תבליט מעוצב של הסמל, ולא סריקת תלת־ממד מדויקת מתוך התמונה.

מקור התמונה: https://otzaria.org/forum/assets/uploads/system/site-logo.png
